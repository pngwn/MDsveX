mdsvex · after remark & rehype

From 293 plugins to 43 features across twelve concerns

mdsvex no longer runs on unified, so its plugin ecosystem starts from zero. We surveyed every plugin on the remark and rehype lists, dropped what PFM already does and what makes no sense for Svelte, grouped the rest by the job a user is doing, and ordered the work so nothing waits on something later.

The map

The bottleneck

The plugin API blocks more than effort does

Plugins can annotate, retag, wrap and append nodes. They can't rewrite text, remove nodes, or read and write document data. Each bar is the monthly downloads of the remark/rehype plugins a missing capability would unblock.

Rewrite or split text 13.1M emoji, typographic details, GitHub refs, mentions, numbering
Remove or move nodes 4.4M GitHub alerts as a plugin, sectionize
Frontmatter, metadata, file path 3.1M TOC data, Document data, citations, per-page options such as toc: false
Async hooks 2.5M build-time diagrams, bibliographies, oEmbed
Diagnostics channel 0.64M link validation, plugin warnings with positions

A plugin can need more than one capability, so the bars overlap. Resolution, Composition, Code and Collections moved to the Vite plugin, so they don't depend on this API. Smart punctuation (17.7M) is now a core option, so it left this chart too.

Decided 10 Oct 2026

Eight decisions

Core defaults

Heading ids and unwrapping lone images go into core, each behind an option. Probably off by default.

GitHub alerts

Deferred for now. They will probably be supported properly.

Heading id syntax

Deferred until it's certain it's needed. It would use square brackets, like everything else.

Transclusion and wiki links

Last. Reuse existing constructs; add syntax only if the value is very strong.

Autolink literals

Not supported. <https://…> already exists and the shorthand adds little.

Smart punctuation

A core feature that can be toggled.

Math output

Temml by default. KaTeX as an option, an optional peer dependency the user installs.

Math syntax

A ```math fence for display and $`…`$ inline. No $…$, no $$, no directives.

Left behind

What we're not building

Already covered ~63 plugins
  • Directivesremark-directive and its relatives, admonitions, containers, custom blocks, shortcodes, remark-mdc, remark-attr (replaced by (k=v) args)
  • TablesGFM tables, extended tables, grid tables, merged cells
  • Inline syntaxstrikethrough, sub/super
  • Frontmatterremark-frontmatter, extract-frontmatter, parse-yaml (swap the parser with frontmatter.parse)
  • HighlightingShiki, Prism, highlight.js, starry-night, pretty-code, code titles, line highlights, twoslash: all built into twinkleplop
  • Structurerehype-rewrite, wrap, components, document, templates: done by templates and component replacement
  • By designremark-breaks (PFM uses \ for hard breaks); bare-URL autolinks (<https://…> already exists)
Pointless for mdsvex ~98 plugins
  • Other outputsman, docx, pdf, Slate, ProseMirror, VDOM, React
  • Markdown formattingreference sorting, heading gaps, prettier: a PFM formatter is a tooling job
  • README generatorslicense, contributors, usage, API, badges
  • HTML minificationabout 25 rehype-minify packages, format, concat, sort attributes: Svelte and Vite own the output
  • Stripping and sanitizingremove comments, unlink, strip HTML, redact, rehype-sanitize (compiling to Svelte already runs code)
  • One-offscode screenshots, CodeSandbox, drop caps, ad injection, scroll-to-top, crypto-address linkers
