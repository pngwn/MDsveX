Code fences highlight many more languages, such as Ruby, PHP, Java, C, C++, C#, SQL, Dockerfile and Vue. The code in these fences is treated as its language, so toggling a comment or matching brackets works as it does in a file of that language. `md` and `markdown` fences are highlighted as Markdown, as they are in the built page, and `svx` fences as mdsvex.
