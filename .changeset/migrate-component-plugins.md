The note left for `rehype-figure`, `remark-figure-caption`, `rehype-mermaid`, `remark-mermaidjs`, `remark-youtube` and `remark-kbd` names the plugin that replaces it: `@mdsvex/plugin-figures`, `@mdsvex/plugin-diagram`, `@mdsvex/plugin-embeds` or `@mdsvex/plugin-elements`. A figure plugin also turns on `unwrap_images`, so an image alone in a figure has no paragraph around it.
