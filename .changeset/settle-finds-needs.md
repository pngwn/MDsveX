An image whose `src` a deferred task set, and a fence with `src=` that a task or an async `document` hook adds, now compile as if they were written in the document. `CompilerSession.settle` makes `Parsed.needs`, `snippets` and `math` again from the settled tree, so `compile_async`, a host that compiles in steps and the Vite plugin import the image and read the file.
